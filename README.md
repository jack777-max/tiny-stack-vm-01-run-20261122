# Stack Forge

A tiny stack VM for the make.fun bounty [Build a tiny stack virtual machine](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one program answers all 40 instances of a set, implementing ISA.md v1 exactly — wrapping 32-bit arithmetic, all ten traps with their exit codes, and the step and output limits.

Run: `node main.ts` (Node 22; reads `$MAKEFUN_INPUT_DIR`, writes `$MAKEFUN_OUTPUT_DIR`).
